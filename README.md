## Why I Built This

I'm a high school student, and whenever exam season rolls around, I need a fast way to test myself on dozens of multiple-choice practice sets — Biology, Chemistry, Physics, Math, History, you name it.

Existing quiz and flashcard apps kept frustrating me with the same issues:
1. **Walled gardens & manual typing**: Entering questions one by one on a phone screen is tedious. I already had questions organized in text or generated by LLMs, but import options were either nonexistent or locked behind paid tiers.
2. **Ads and forced accounts**: Opening an app to do a quick 5-minute study drill shouldn't require creating an account, logging in, or sitting through 30-second unskippable ads.
3. **Broken math & scientific notation**: Most apps treat questions as plain text, turning formulas like $\int_{0}^{\pi} \sin(x) dx$ or chemical equations into an unreadable mess.
4. **Rigid review systems**: After submitting an exam, getting a red "Incorrect" without an explanation doesn't help you learn.

So I built **Pozix**: a lightweight, distraction-free study tool where you simply drop in a JSON file and start practicing immediately. I gave it a polished Material 3 design, tactile spring physics, crisp KaTeX rendering, and a built-in AI assistant to break down tricky questions when you make a mistake.

## Key Highlights

### ⚡ Drop-in JSON Import & System Sharing
- **Zero-friction setup**: Paste raw JSON, pick a `.json` file from device storage, or share text/files straight from your browser, notes, or messaging apps via Android's native `ACTION_SEND` intent.
- **Built-in validator**: Instant syntax inspection with line-and-column diagnostic alerts before importing.

### 📝 Smart Exam & Practice Player
- **Adaptive question cards**: Smooth content-aware sizing that accommodates single questions, passages, or attached visual media.
- **Floating navigation island**: Compact "Previous" and "Next Question" buttons float freely above answer choices with zero background blocking — cards and explanations glide seamlessly underneath.
- **Timed exam mode**: Live countdown timer, real-time score calculation, and a quick-jump question palette grid.

### 📐 Scientific & Math Rendering (KaTeX / LaTeX)
- First-class support for inline and display math formulas via KaTeX.
- Preserves font scale, baseline vertical alignments, and supports horizontal scrolling for wide formulas without clipping subscripts or limits.

### 🤖 BYOK (Bring Your Own Key) AI Assistant
- Chat and study companion powered by your own API keys (DeepSeek, OpenAI, Gemini, Groq, or any OpenAI-compatible provider).
- Streaming Server-Sent Events (SSE) responses, reasoning effort adjustment ("Think" intensity), and one-tap exam review to analyze wrong answers.

### 🎨 Material 3 & Tactile Physics
- **Dynamic luminance status bar**: System bar colors dynamically synchronize with the app's background luminance across both Light and Dark themes.
- **BouncyContainer overscroll**: Custom logarithmic resistance and spring rebound physics (`NestedScrollConnection`) when dragging to the edges of lists and bottom sheets.
- **14 curated typography styles**: Switch between System Default, EB Garamond, Space Mono, Comic Relief, Ubuntu, Libertinus Serif, Alata, Aleo, Changa, Tenor Sans, and more.

### 🔒 100% Offline-First & Private
- All quiz sets, bookmarks, and test history are stored locally in an encrypted Room SQLite database on your device.
- No mandatory telemetry, no analytics, no third-party tracking.
- Optional cloud backup via Cloudflare Workers & D1 if you want multi-device sync.

## JSON Format Specification

Pozix supports single-choice and true/false question types. Here is a minimal JSON schema you can use or ask any AI to generate:

```json
{
  "title": "Cell Biology Review",
  "description": "Quick revision on cellular respiration and photosynthesis",
  "questions": [
    {
      "type": "single_choice",
      "question": "Which organelle is known as the powerhouse of the cell?",
      "options": [
        "Endoplasmic Reticulum",
        "Mitochondria",
        "Golgi Apparatus",
        "Ribosome"
      ],
      "correctIndex": 1,
      "explanation": "Mitochondria generate most of the chemical energy needed to power the cell's biochemical reactions."
    },
    {
      "type": "true_false",
      "question": "Photosynthesis converts light energy into chemical energy stored in glucose.",
      "options": [
        "True",
        "False"
      ],
      "correctIndex": 0,
      "explanation": "Photosynthesis produces glucose and oxygen from carbon dioxide and water using sunlight."
    }
  ]
}
```

## Tech Stack

Built simply and cleanly with modern Android architecture:

- **Language**: Kotlin 2.0
- **UI Toolkit**: Jetpack Compose + Material 3 (Edge-to-Edge window insets)
- **Architecture**: MVVM with Unidirectional Data Flow (UDF) & StateFlow
- **Database**: Room Database (SQLite) with atomic operations
- **Settings**: Jetpack DataStore Preferences
- **Math Engine**: KaTeX & Markdown rich content parser
- **Networking**: OkHttp3 with streaming SSE support
- **Physics**: Custom `NestedScrollConnection` with logarithmic dampening & spring overshoot

## Building From Source

If you want to build the project locally using Android Studio:

1. Clone the repository:
   ```bash
   git clone https://github.com/dev-hkm/Pozix.git
   cd Pozix
   ```
2. Open the project in Android Studio (Ladybug / Meerkat / Panda) with JDK 17+.
3. Build the debug APK:
   ```bash
   ./gradlew assembleDebug
   ```
